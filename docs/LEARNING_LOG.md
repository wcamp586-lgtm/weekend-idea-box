# 学习日志

## 第 1 课：从想法到可执行工程

### 本课只掌握三件事

1. 一句话产品定义必须包含用户、问题和结果。
2. MVP 必须拥有一条从头到尾可验收的核心路径。
3. “明确不做什么”与功能清单同样重要，它能阻止 AI 把项目越做越大。

### 已完成

- 产品一句话定义、目标用户和核心问题。
- MVP 范围、非目标、数据模型和九条验收标准。
- 桌面与手机完整主界面概念。
- React + TypeScript + Vite 工程骨架。
- 依赖安装、静态检查和生产构建验证。
- 第一次 Git 提交。

### 课后自检

不看规格文件，尝试用自己的话回答：

1. 这个产品帮助谁解决什么问题？
2. 从开始到获得价值的最短操作路径是什么？
3. 哪三个听起来不错的功能被我们主动排除，为什么？
